# AI Team Collaboration Assistant

**Capstone 11 | Simple GitHub-based project**

## Project question
Can AI make team projects smoother by organising roles, meetings and progress?

## Sample project
Build a simple **Student Event Planner** in 1 week. Deliverables: event plan, task board, meeting notes, weekly progress summary, risk list, and final demo.

## Team and roles
| Role | Owner | Responsibility |
|---|---|---|
| Project lead | Member 1 | Timeline, meetings, final demo |
| Researcher | Member 2 | Requirements and risk research |
| Documentation lead | Member 3 | Notes, README, prompt library |
| QA / AI verifier | Member 4 | Check AI output and record corrections |

Replace Member 1–4 with your team names.

## How to use this repository
1. Check `project/task-board.md` and assign each task.
2. Use prompts in `prompts/prompt-library.md`.
3. Add meeting outcomes to `meetings/meeting-notes.md`.
4. Check AI outputs using `verification/verification-report.md`.
5. Review `reports/feedback-and-before-after.md` and present the demo.

## AI tools used
ChatGPT (planning, prompts, summaries), GitHub (repository and task tracking), GitHub Actions (scheduled weekly reminder/summary issue).

## Ethical use
Do not upload private student data. Verify AI-generated facts and dates. Cite external sources. Disclose AI assistance. AI suggestions are drafts; the team makes final decisions.

## Final demo (2 minutes)
Show the task board → demonstrate one prompt → show a meeting action item → explain verification → show the weekly automation workflow.

## Skills demonstrated
AI foundations, prompt engineering, research, content creation, automation, verification, responsible AI.

## Project Results

### Before AI
- Task allocation was manual.
- Meeting notes were difficult to organise.
- Progress updates were not centralised.

### After AI
- AI generated task breakdowns and meeting agendas.
- GitHub tracked tasks and responsibilities.
- GitHub Actions created weekly summary issues.

### Conclusion
AI helped improve project organisation by making task ownership, meeting outcomes, and progress updates easier to manage.

### Limitations
- AI can generate incorrect information.
- Team members must verify AI-generated results.
- Automation requires GitHub Actions to be enabled.

### Responsible AI
We avoided sharing private information, verified AI outputs, and disclosed the use of AI tools.

### Tools Used
ChatGPT, GitHub, GitHub Actions.
